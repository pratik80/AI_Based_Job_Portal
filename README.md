Job Portal – AI Resume Shortlisting System
1. Project Overview

Job Portal is an AI-powered web application for automated resume screening.
The system extracts important information from resumes using Natural Language Processing.
It compares extracted candidate information with a given job description.
The application helps recruiters identify suitable candidates efficiently.
It reduces the manual effort involved in reviewing multiple resumes.

2. Key Features
Upload and process candidate resumes.
Extract relevant information from resumes automatically.
Analyze skills, education, experience, and other entities.
Process job descriptions and identify required skills.
Compare resumes with job descriptions.
Calculate candidate-job relevance using AI techniques.
Shortlist candidates based on matching scores.
Provide a simple and user-friendly web interface.
3. Technologies Used
Programming Language: Python
Frontend: HTML5, CSS3, JavaScript, Bootstrap
Backend: Flask
NLP: Natural Language Processing
NER: Named Entity Recognition
Machine Learning: Semi-Supervised Learning
NLP Library: spaCy
Classification: Logistic Regression
4. System Workflow
Recruiter uploads a resume to the portal.
The system extracts text and relevant information.
NLP techniques preprocess and clean the extracted text.
Named Entity Recognition identifies important entities.
The job description is processed using similar NLP techniques.
Resume features are compared with job requirements.
The trained machine learning model evaluates the candidate.
Candidates are ranked according to their relevance.
The most suitable resumes are shortlisted.
Results are displayed through the web interface.
5. Machine Learning

The project uses Logistic Regression for classification and prediction.
Semi-Supervised Learning can be used to improve the model with limited labelled data.
spaCy provides NLP processing and Named Entity Recognition capabilities.
The model helps determine whether a resume is relevant to a particular job.

6. Objective

The main objective is to make recruitment faster and more efficient.
The system minimizes repetitive manual resume screening.
It provides recruiters with an AI-assisted method for candidate selection.

7. Future Scope

The system can be extended with advanced deep learning models.
Additional resume formats and languages can be supported.
Recruiters can be provided with advanced analytics and candidate rankings.
Integration with online job boards and recruitment platforms can also be added.
